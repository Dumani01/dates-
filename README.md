# ¿Quieres salir conmigo?

Página web interactiva hecha con HTML, CSS y JavaScript.

## Funciones

- Pregunta inicial: "¿Quieres salir conmigo?"
- Botón "Sí".
- Botón "No" que se aleja cuando el mouse se acerca.
- En móvil, el botón "No" también se mueve al intentar tocarlo.
- Selector de fecha.
- Varias opciones de comida.
- Resumen final de la cita.
- Diseño responsive para computadora y teléfono.

## Cómo abrirla

1. Descomprime el ZIP.
2. Abre la carpeta `quieres_salir_conmigo`.
3. Haz doble clic en `index.html`.

No necesitas instalar Node.js, React ni ningún paquete.

## Archivos

- `index.html`: estructura de la página.
- `styles.css`: diseño, animaciones y estilos responsive.
- `script.js`: interacción, botón "No", formularios y navegación.
